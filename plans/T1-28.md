## Idea
1. **구조를 먼저 만들고 옛 경로는 shim으로 살린다(D18).** `kosis_chat/<stage>/` 폴더와 `shared/ schemas/ graph/ adapters/ legacy/`를 S1에서 만들고, 옛 모듈(`kosis_chat.data.loader` 등 35경로)은 재export 파일로 남긴다. `import *`는 밑줄 이름(`compute.engine._read`: `llm/analyze_plan.py:21`·`tests/test_semantics.py:9`, `api._build`·`api._cached`: Phase 2 `evals/trace.py:61`)을 빼먹으므로 shim은 **이름을 하나씩 적는 명시적 재export**로 쓰고, 실제로 쓰이는 이름·호출 인자·반환 객체를 `docs/compat-surface.md` + `tests/test_compat_surface.py`로 고정한다. tests 35곳·eval 17곳·Phase 2 7곳은 수정 0건.
2. **노드 경계만 Pydantic(D5 a).** `Verdict Plan Built Computed Placed Alternatives` 등 12개 dataclass를 단계별 `schemas.py`의 Pydantic 모델로 바꾸고, 대용량 `TableInput/Cell/TableIndex`는 dataclass로 `StatResources`(D4 a)에 둔다.
3. **입력은 로드된 Parquet 표(D13).** 모듈은 파일을 열지 않는다. `adapters/parquet.py`만 파일을 열고, `prepare` 노드가 행→셀 변환·단위 추론·clean·색인을 한다(내용 해시 캐시, D24 a). 표 메타는 `info` 우선, 없으면 카탈로그(D23 c).
4. **LLM은 생성 시 주입(D25).** `StatModule(llm=LLMConfig(api_key: SecretStr, model, provider))`. 모듈 안에서 `.env`·`os.environ`·`configs/model.yaml`을 읽지 않는다. 키가 없으면 **LLM 노드에 들어갈 때** 에러(D25-3 b, 생성 시점이 아님: 규칙만으로 끝나는 거절·되묻기는 키 없이도 돈다), `provider="mock"`은 테스트·CI 전용(N3). provider → 클라이언트 클래스 등록표(E5).
5. **차트는 별도 출력(D14 b, D22 b, N4).** `StatAnswer.chart`는 S5에서 제거하고 `StatOutput.chart: ChartSpec | None`으로만 낸다(Phase 3용). ChartSpec은 data + kind 필수, Vega-Lite spec은 선택(V1 c).
6. **패리티 게이트(D11 a).** S0~S4: mock 90문항 `results.jsonl`이 S0 저장본과 바이트 동일(휘발 필드 `latency_seconds retry_wait_seconds started_at usage spans 시각` 제외). `attempts`와 호출 상태(`status`)는 바이트 비교에서 빼되 **별도 항목으로 같은지 검사**한다. S5~S6: 출력 형식이 바뀌므로(`StatAnswer.chart` 제거, `chart` = ChartSpec) `eval/parity.py --mode semantic`으로 옛·새 결과를 공통 형식으로 바꿔 판정·route·facts(`source_ref`·값·단위)·근거·거절 문구·차트 데이터(kind, 점별 값·단위·fact_id)를 비교한다. HCX(S5): verdict·facts 동일, 문장 diff 허용. 사용자가 실행·판정한다.
