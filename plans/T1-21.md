# T1-21 사람 판정 + 자연어 품질 0~2점

## Goal
- 완료 기준 (TASK.md 그대로): 리뷰 양식에 자연어 품질 0~2점 칸을 추가하고 T1-20 결과 62문항 사람 판정을 완료한다. 품질 평균과 0점 사례를 기록한다
- Baseline: 리뷰 양식(`eval/review.py`) 11칸에 품질 칸 없음. 사람 판정 기록은 Notion 두 페이지(10/26, 품질 문제 6건)뿐.
  이 PC의 62문항 실행 `eval/results/20261023-144352-T1-19-edge`(B0, HCX-DASH-002)는 62/62 미판정. T1-20 실행(B0·C 62문항)은 다른 PC에 있다.
- **범위 한정**: 사람 판정 자체는 사람이 한다. 이 태스크의 코드 산출물은 양식·검증·집계이고, "62문항 판정 완료"는 사용자·팀이 시트를 채운 뒤 `apply`로 닫는다.

## Idea
`review export`가 만드는 시트에 `quality_score`(0/1/2)·`quality_note` 칸을 더한다. 루브릭은 T1-26 judge와 같은 문장(답한 문항 / 거절·되묻기 문항 기준)을 시트 머리 안내와 README에 둔다.
`review apply`는 0~2 밖 값을 거부하고 결과에 `quality_score`를 저장한다. `scorer`는 확정된 행의 품질 평균·0점 문항을 요약하고 `eval-history`에 남긴다.

## Option A — 블라인드 사람 판정 + 판정 후 judge와 조인
- 접근: 시트에 `quality_score`(0/1/2)·`quality_note` 칸만 추가하고 judge 점수는 **보여 주지 않는다**. export는 미판정 행과 "판정은 확정됐지만 품질이 빈 행"을 함께 내보내고, apply는 확정된 행에는 품질만 갱신한다(0~2 밖 값 거부). `scorer`는 품질 평균(채점 n/전체 N 명시)·0점 문항을 `summary.json`과 출력에 낸다(기존 eval-history 표의 칸 수는 바꾸지 않음). 실행 폴더에 `quality.jsonl`(T1-26)이 있으면 `(question_id, run_index)`로 조인해 사람-judge **일치율, 3×3 혼동표, kind별(답한 문항 / 거절·되묻기) 일치율, 가중 κ**를 함께 낸다. judge 쪽 점수는 리포트에 쓰는 최종 점수(`score`, 표기 문제 시 1점 상한)를 쓴다.
- 예상 성능 향상: 자연어 품질 사람 점수 기록 수단 0 → 1. judge-사람 일치도를 오염 없이 처음 측정(수치는 판정 후 확정). 판정 시간 단축은 없음.
- 실질 반영 이점: 평가 기준 "응답 품질"에 사람 점수. T1-26 judge가 사람을 대신할 수 있는지 판단할 깨끗한 근거.
- 비용·리스크: 반나절(코드). judge 실행(HCX-007 약 62회, 약 10분)은 조인 측정 때 별도. 사람 판정 시간은 사용자 몫.

## Option B — judge 제안을 시트에 보여 줌
- 접근: A의 칸에 더해 `judge_quality`·`judge_reason`·`format_issues` 참고 칸을 채운다(judge 실행 선행).
- 예상 성능 향상: 판정이 빨라질 수 있음(측정값 없음). 대신 일치도가 앵커링으로 부풀어 T1-26 보정 근거로 쓸 수 없다.
- 실질 반영 이점: 판정 편의.
- 비용·리스크: 반나절 + judge 실행. 측정 오염.

## Option C — 품질 전용 시트 분리
- 접근: 정오 판정 시트와 별도로 `review quality-export/apply`를 두고, 품질 점수만 따로 매긴다(다른 사람이 나눠 맡기 쉬움).
- 예상 성능 향상: A와 같은 지표. 판정 작업을 둘로 나눠 병행 가능.
- 실질 반영 이점: 정오 판정과 품질 판정의 독립성(서로의 판단에 끌리지 않음).
- 비용·리스크: 시트·명령이 두 벌이 되어 관리 부담. 같은 답을 두 번 읽어야 한다.

## Recommendation
**옵션 A**. 블라인드로 판정해야 일치도가 의미가 있고, 조인은 판정 후 코드가 하므로 B의 이점(보정 근거)은 그대로 얻는다. 같은 시트에서 정오와 품질을 함께 보면 답을 한 번만 읽는다(C 대비).
